# 谷粒商城技术文档

## 1. 项目概述

谷粒商城（guli-mall）是一个基于 Spring Cloud 微服务架构的电商平台，采用前后端分离设计，涵盖商品管理、订单、优惠券、库存、搜索、会员、认证、秒杀等完整电商业务模块。

**项目定位**：B2C 电商平台，支持多商家入驻、商品搜索、购物车、订单管理、库存管理、秒杀等核心功能。

***

                          │

                          │

- **mall-gateway**：所有请求的入口，路由至各业务服务。
- **mall-common**：被所有业务服务依赖，提供通用能力。
- **mall-seckill**：秒杀服务，通过 Feign 调用 `mall-product`（查询 SKU）、`mall-coupon`（查询秒杀活动），将秒杀下单请求经 RabbitMQ 投递给 `mall-order` 异步创建订单，并依赖 Redis 存储秒杀场次与商品信号量（防超卖）。
- **消息驱动**：`mall-order` 监听 RabbitMQ 的「订单延迟关闭」「秒杀订单」队列，`mall-ware` 监听「库存解锁」队列，`mall-seckill` 与 `mall-order` 通过 MQ 进行流量削峰与解耦。

## 4. 核心业务流程

### 4.1 商品搜索流程

```
用户请求 → Nginx → Gateway → mall-search → Elasticsearch
                                               ↓
                                           返回搜索结果
```

**关键技术点**：

- Elasticsearch 7.17.0 实现全文检索
- IK 分词器支持中文分词
- 商品索引结构包含 SKU、SPU、分类、品牌等信息

### 4.2 订单创建流程

```
用户下单 → Gateway → mall-order
                         │
              ┌──────────┼──────────┐
              ▼          ▼          ▼
         mall-product mall-ware mall-coupon
              │          │          │
              └──────────┴──────────┘
                         │
                     扣减库存/优惠券
                         │
                     创建订单
```

**关键技术点**：

- Feign 远程调用多个微服务
- 分布式事务处理
- Redis 分布式锁保证库存一致性

### 4.3 认证登录流程

```
用户登录 → auth.gulimall → mall-auth-server
                              │
              ┌───────────────┼───────────────┐
              ▼               ▼               ▼
           mall-member    社交登录(OAuth)    Redis Session
                              │
                         返回Token/Session
```

### 4.4 秒杀业务流程

```
定时上架(每天凌晨) → mall-seckill 从 mall-coupon/mall-product 拉取秒杀活动与SKU
                              ↓
       写入 Redis：秒杀场次 / 商品信号量(库存) / 随机码防刷
                              ↓
用户访问 seckill.gulimall.com → Gateway → mall-seckill
                              ↓
       校验登录(session) → 校验随机码/信号量(防超卖)
                              ↓
       发送秒杀消息至 RabbitMQ(含用户与SKU)
                              ↓
mall-order 异步消费 → 创建订单 → 扣减库存(mall-ware)
```

**关键技术点**：

- 秒杀场次与商品信号量预存 Redis，利用 Redis 原子递减实现防超卖。
- 商品随机码（秒杀开始时暴露）防止恶意刷接口。
- 秒杀请求先入 RabbitMQ，由 `mall-order` 异步消费，实现流量削峰。
- 订单超时由 RabbitMQ 延迟队列关闭并释放库存。

各微服务通过 Feign 实现跨服务调用，核心调用关系：

| 调用方          | 被调用方         | 调用接口                                                                      |
| :----------- | :----------- | :------------------------------------------------------------------------ |
| mall-product | mall-coupon  | `CouponFeignService.saveSpuBounds()` / `saveSkuReduction()`               |
| mall-product | mall-search  | `SearchFeignService`                                                      |
| mall-product | mall-ware    | `WareFeignService`                                                        |
| mall-cart    | mall-product | `ProductFeignService.getInfo()` / `getSkuSaleAttrValues()` / `getPrice()` |

**Feign 调用示例**：

```java
@FeignClient("mall-coupon")
public interface CouponFeignService {
    @PostMapping("/coupon/spubounds/save")
    R saveSpuBounds(@RequestBody SpuBoundTo spuBoundTo);
    
    @PostMapping("/coupon/skufullreduction/saveinfo")
    R saveSkuReduction(@RequestBody SkuReductionTo skuReductionTo);
}
```

**熔断降级**：

- 通过 `@FeignClient` 的 `fallback` 属性配置降级类
- 如 `SeckillFeignServiceFallBack` 实现服务降级

## 9. 安全设计

### 9.1 认证方案

- **后台管理**：基于 Shiro 的 JWT 认证
- **前台用户**：基于 Spring Security + Redis Session
- **社交登录**：OAuth2.0 协议（微信/QQ/微博）

### 9.2 限流熔断

- 使用 **Sentinel** 进行接口限流和熔断降级
- 配置 `feign.sentinel.enabled=true` 开启 Feign 熔断支持
- 使用 **RabbitMQ** 实现服务间异步解耦与流量削峰：秒杀请求经 MQ 异步创建订单，订单超时关闭、库存解锁均通过 MQ 可靠消息驱动（详见 4.2、4.4）

### 9.3 数据安全

- 密码采用 BCrypt 加密存储
- 敏感配置通过 Nacos 配置中心管理
- 接口请求参数校验（JSR-303）

## 11. 总结

谷粒商城是一个技术栈完整、架构清晰的微服务电商项目，涵盖了现代电商平台所需的核心业务模块。项目采用 Spring Cloud 生态体系，具备良好的可扩展性和高可用性。核心亮点包括：

1. **微服务架构**：服务拆分合理，职责清晰
2. **分布式能力**：支持服务注册发现、负载均衡、消息驱动（RabbitMQ）与分布式锁（Redisson）
3. **高性能搜索**：基于 Elasticsearch 的全文检索
4. **缓存策略**：Redis + Spring Cache 提升性能
5. **统一网关**：Spring Cloud Gateway 实现路由转发和安全控制
6. **熔断降级**：Sentinel 保障系统稳定性

项目适合作为学习微服务架构和电商业务开发的参考案例。
